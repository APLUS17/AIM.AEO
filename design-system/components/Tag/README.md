# Tag

A small uppercase `overline` label in a `radius-tags` capsule — brass on fog by default.

**Consumer provides:** a `<span class="el-tag">` with one or two words; add `el-tag--outline` (steel text, mist border) or `el-tag--ink` (white on graphite).

- Use for categories and status labels on cards, never as buttons.
- Brass text is 4.9:1 on fog; don't place brass tags on `color-ivory` (4.3:1).
