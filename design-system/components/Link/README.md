# Link

Inline text link in the surrounding text colour with a 1px `color-ember-orange` underline offset 3px, plus a quiet `el-link--utility` variant for footers.

**Consumer provides:** an `<a class="el-link">` inside running text; add `el-link--utility` for footer and legal links.

- Use the ember link for the one or two most important links on a page — it is the main place the accent appears.
- Hover thickens the underline to 2px. Never colour the link text itself orange on light grounds (2.9:1).
- Utility links are PolySans 13px `color-slate`, no underline; hover goes to `color-graphite`.
