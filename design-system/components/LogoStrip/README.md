# LogoStrip

A row of monochrome partner logos on white, with a brass `caption-display` line above.

**Consumer provides:** real partner logos as single-ink SVGs or PNGs in `color-graphite`, each with alt text naming the partner, and the caption text. The preview uses abstract placeholder marks — replace them; never redraw a partner's logo.

- Logos are monochrome only; no colour, boxes or borders around them.
- Gap is `element-gap` vertically and `spacing-40` horizontally; logos share one optical height (about 28px).
- Place it full-width on white directly below the hero.
