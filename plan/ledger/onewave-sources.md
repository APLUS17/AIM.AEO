## What this tells us
1. **Vendor documentation does most of the work.** The majority of their citations are official docs, help centres, announcements and GitHub pages.
2. **Independent sources are used sparingly:** Gartner, an arXiv paper, a trade news site, and named analysts' posts.
3. **Credibility also comes from a practitioner's voice** ("we use both daily"). They assert this without data.
4. **Their weak spots, which we should not copy:** several posts carry statistics with no visible source (the real estate post has about a dozen), claims are named without links, and some figures such as "expert quotes raised citations by over 40 percent" have no source.
5. **They only publish their own test data in the one benchmark post.** So AiM's data posts are a differentiator, not a requirement.

## What this changes for AiM

## One thing we cannot copy
OneWave leans on first-hand client experience ("a South Florida brokerage saw a 40% lift"). AiM has no verified client results to cite. We write only what we can show: sourced facts, tests we ran, and our own judgment, labelled as judgment.
